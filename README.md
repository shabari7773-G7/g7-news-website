# G7 NEWS Website

A modern, responsive news website for G7 NEWS.

## Getting Started

1. Open `index.html` in a browser to view the website locally.

## Deployment

Upload this folder to any of these platforms to publish your website for free:

- **GitHub Pages** - Push to GitHub and enable Pages in repository settings
- **Netlify** - Connect your repository at [netlify.com](https://netlify.com)
- **Cloudflare Pages** - Connect your repository at [pages.cloudflare.com](https://pages.cloudflare.com)

## Features

- Responsive grid layout
- Modern card-based design
- News ticker
- Mobile-friendly navigation

## Files

- `index.html` - Main website structure
- `style.css` - Styling and layout
- `README.md` - Documentation
